# Freedom Lab NYC — Open Source AI Skills

Downloadable skill packages for AI agents. Each skill teaches your agent a specific workflow — from making purchases with Bitcoin to creating videos programmatically.

**Browse skills on the web:** [freedomlab.nyc/resources](https://freedomlab.nyc/resources/#ai-skills)

## Skills

| Skill | Description |
|-------|-------------|
| [Buy With Bitcoin (Bitrefill)](buy-with-bitcoin-bitrefill/) | Spend Bitcoin at any online store using Lightning → Bitrefill Visa → automated checkout |
| [Skill Creator](skill-creator/) | Teach your agent how to create, edit, and audit skills |
| [Quality Toolkit](quality-toolkit/) | Premise Check + Stress Test — QA for AI agent workflows |
| [Programmatic Video](programmatic-video/) | Create deterministic video content with Three.js, Remotion, and FFmpeg |
| [X/Twitter Research](x-research/) | Research accounts, map trust networks, find real recommendations |
| [Interactive Device Viewer](interactive-device-viewer/) | Build, QA, and publish an interactive Three.js exploded-assembly device page (the voicehardware site on freedomlab.nyc) |
| [Nostr App Development](nostr-app-development/) | Build Nostr relay read/write apps, NIP-05 verification, livestream announcements + stdlib relay probe || [Hermes Gadget Boards](hermes-gadget-boards/) | Flash and pair ESP32-S3 hold-to-talk voice boards for a local Hermes gateway, with field-verified bring-up data || [MediaMTX Livestream Hub](mediamtx-livestream-hub/) | Self-hosted RTMP ingest → HLS out → platform restream fanout → Nostr announce || [Voice Transcribe](voice-transcribe/) | Local faster-whisper transcription with optional Ollama summaries/action items |
| [Android TV ADB Debloater](android-tv-adb-debloater/) | Debloat, launcher-swap, and video-wallpaper an NVIDIA Shield / Android TV box over Wi-Fi ADB |
| [Tailscale Hermes Remote](tailscale-hermes-remote/) | Reach a self-hosted Hermes dashboard from iOS/desktop over your tailnet — no public ports |
## Installing a Skill

Download the `.skill` file from the skill's page on [freedomlab.nyc](https://freedomlab.nyc/resources/#ai-skills), or clone this repo and point your agent at the skill's `SKILL.md`.
