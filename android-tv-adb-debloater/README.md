# Android TV ADB Debloater

Turn a laggy, ad-laden NVIDIA Shield / Android TV box into a clean media machine — all from a PC over Wi-Fi ADB. Teaches an agent the things the internet gets wrong: why `pm disable-user` on NVIDIA telemetry silently reverts at boot (and what actually persists), safe package deny-lists, HOME-role swap verification that doesn't lie, D-pad-only system pickers, Couchy launcher video-wallpaper gotchas, tvOS-launcher aerial-style frame scenes, ffmpeg zoompan loops from stills, and screencap-diff motion verification.
