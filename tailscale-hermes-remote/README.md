# Tailscale Hermes Remote

Reach your self-hosted Hermes dashboard from the official iOS/desktop app anywhere on earth — without exposing a single port to the public internet. Tailscale's outbound-only, device-paired overlay plus one tightly-scoped firewall rule, verified end to end.

Teaches an agent the parts that trip everyone: the browser "logged in successful" trap (the device still needs approving on the auth page), why the CLI needs an operator set, `302` as the health signal, tailnet-ping round-trip proof, 180-day key-expiry drop-offs, and strict rules for what NEVER goes in a shared doc — IPs and credentials are fetched live, never written down.
