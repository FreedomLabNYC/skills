# Quality Toolkit for OpenClaw

Two skills that work together: **Premise Check** challenges your assumptions before building, **Stress Test** hunts for bugs after.

See [freedomlab.nyc/resources/quality-toolkit](https://freedomlab.nyc/resources/quality-toolkit/) for full details.

## Contents

- `premise-check-SKILL.md` — 7-step reasoning checklist (max 2 passes, then execute)
- `stress-test-SKILL.md` — 4-layer testing checklist for scripts, APIs, cron jobs, services, and sites
